# harvienregering.nu

A tiny joke website created around the 2021 Swedish government crisis. Its
name translates to “do we have a government?”, and the page answered with a
deliberately brief status update as events unfolded.

The project remains online as a small time capsule from an unusually turbulent
period in Swedish politics. It is not a news service, and its answer should not
be treated as current information about the Swedish government.

## Background

On 21 June 2021, Prime Minister Stefan Löfven lost a vote of no confidence in
the Riksdag. After a period of government negotiations and rounds of talks led
by the Speaker, Löfven was re-elected prime minister on 7 July 2021. The site’s
single-line response changed along with the situation.

## Running locally

The site is a single static HTML file. Open `src/index.html` in a browser or
serve the `src` directory with any static web server.
